 Banking System Web Application

  About the Project--
This is a web-based Banking System developed using Java and Spring Boot. It allows users to create bank accounts, deposit money, withdraw money, transfer money, and view transaction history.

 Technologies Used--
- Java 17
- Spring Boot
- Spring Data JPA
- Hibernate
- PostgreSQL
- HTML
- CSS
- JavaScript
- Maven

   Features--
- Create a bank account
- View account details
- Deposit money
- Withdraw money
- Transfer money between accounts
- View transaction history
- Input validation and exception handling
- Store account and transaction data in PostgreSQL


 Database--
PostgreSQL is used to store bank account details and transaction records.

Database name: banking_db

 How to Run--
1. Install Java 17, Maven, and PostgreSQL.
2. Create a PostgreSQL database named banking_db.
3. Configure the database username and password in application.properties or environment variables.
4. Open the project in Eclipse or Spring Tool Suite.
5. Run the Spring Boot application.


 API Testing--
REST APIs can be tested using Postman.
